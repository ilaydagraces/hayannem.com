# Hayannem
React + Vite ile hazırlanmış hayvan ürünleri mağazası demo projesi.

## Çalıştırma
1. ZIP dosyasını çıkar.
2. Çıkan `hayannem` klasörünü VS Code ile aç.
3. Terminal > New Terminal seç.
4. Sırayla çalıştır:
   `npm install`
   `npm run dev`
5. Terminalde çıkan localhost bağlantısını aç.

Ürün arama, kategori filtreleme, sıralama, favoriler ve sepet demo olarak çalışır. Gerçek ödeme sistemi bağlı değildir.
